# Solucioneomos React Workspace

React, TypeScript, Vite 기반의 UI 쇼케이스 및 생산성 도구 모음입니다.

## 실행

```bash
cd vite-project
npm install
npm run dev
```

## 주요 기능

- 컴포넌트 쇼케이스: 버튼, 카드, 탭, 모달, 캘린더 등 UI 패턴 탐색
- 전체 앱 예시: 프로젝트 관리, 피드백 인박스, 청소 확인 플로우, Chrome 확장 템플릿
- 도구: Form Builder, SVG Editor, Theme Builder, Accessibility Checker, Logo Generator, Power TS Toolkit
- 라이브러리: YAML 템플릿, Custom SVG Library
- 전역 기능: 다크 모드, 한국어/영어 전환, `Ctrl+K` 검색, workspace 백업/복원

## 개발 명령

```bash
npm run typecheck
npm run build
npm run preview
npm run docs
```

## 프로젝트 위치

- 앱 소스: `vite-project/src`
- 라우트/내비게이션: `vite-project/src/app/config`
- 공통 UI: `vite-project/src/app/components`
- 도메인 기능: `vite-project/src/app/features`
- 정적 데이터: `vite-project/src/app/data`
